Intro:

A Hospital Management System needs to support several different activities, including registering patients, arranging appointments and allowing doctors and administrative staff to access the information they need. These activities are linked, so the way the system is designed can have a big effect on how easy it is to maintain and how well it performs as the number of users increases. This report looks at how software engineering principles can be applied to a Hospital Management System. The main software paradigm considered is Object-Oriented Programming (OOP), which is then applied to a microservice-based system. The microservice chosen for this report is an Appointment Management Service. Its main purpose is to handle the creation, modification and cancellation of patient appointments. Software engineering involves planning, designing, testing, deploying and maintaining a system, as well as working effectively as a team. The lecture material also highlights qualities such as reliability, scalability, reusability, security and usability. These are important for a hospital system because it needs to be reliable and able to handle sensitive information. Using microservices means that different areas of the hospital system can be separated based on what they are responsible for. For example, appointment management can be handled by its own service rather than being part of one large application. This makes it possible to focus on the requirements of appointments while allowing other parts of the hospital system to be developed separately. The following sections examine the use of OOP in the Hospital Management System and then apply the microservice approach to the Appointment Management Service. The design considers the main domain entities, value objects, services and infrastructure needed by the microservice, along with relevant security, ethical and social considerations.
